## Backend Software Engineer

### About the role

Join our platform team building high throughput backend services. You will own API design, data persistence, and reliability for services used by internal product teams.

### Required qualifications

- Degree in Computer Science or equivalent practical experience
- Strong proficiency in at least one backend language (**Python**, **Go**, or **Node.js**)
- Experience designing **REST APIs** and working with **SQL** databases (**PostgreSQL** preferred)
- **Redis** or similar caching; understanding of cache aside and write through patterns
- **Docker** containers and **CI/CD** with **Git**
- **Cloud** deployment experience (AWS, Azure, or GCP)
- **Agile** team experience; receives **feedback** well in code review

### Preferred qualifications

- **gRPC** or microservices architecture
- Message queues (**Kafka**, RabbitMQ, or BullMQ)
- Observability: metrics, dashboards, load testing
- **Kubernetes** (nice to have)

### Responsibilities

- Build and maintain backend services with clear API contracts
- Optimize database queries and caching for latency and throughput
- Collaborate with frontend and data teams on integration
- Participate in on call rotation and incident postmortems
