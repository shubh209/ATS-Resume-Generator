## Software Engineer, Cloud Engineering — Sonos

### Company overview

Sonos Cloud Engineering builds the cloud technology stack and features powering Sonos products, used by customer systems, Sonos-internal services, and partner systems.

### What you'll do

- Design and develop cloud-based software used by customer, internal, and partner systems.
- Use GenAI tools (GitHub Copilot, Claude Code, Google Gemini) in the daily workflow to accelerate code generation, testing, and debugging.
- Participate in the full SDLC: planning, requirements, development, unit testing.
- Work in an agile environment; help scope user stories; participate in code and design reviews.
- Support production services in a DevOps environment: monitor health, deploy, join on-call and incident handling.
- Follow best practices for security, scalability, cost, and performance; build automated tests and CI/CD deployment processes.

### Basic qualifications

- Degree in CS/related or equivalent experience.
- 1-4 years with server-side languages/frameworks such as JavaScript/TypeScript (Node.js) or Java (Spring Boot).
- Developing and deploying software with at least one public cloud (AWS, GCP, Azure).
- Exposure to agile methodologies.
- OOD/coding (Node.js/Java preferred), JSON, and API development.
- Thrives in a fast-paced environment.

### Preferred qualifications

- AWS components (ElastiCache, RDS, EC2, Lambda, cloud networking).
- Data/metrics for service health; observability toolstacks.
- Containers and Kubernetes.
- Connected devices at scale, authn/authz, REST web services, SQL and NoSQL data modeling, search engines, data pipelines.
- Integrating GenAI coding assistants into the workflow.
