## Software Engineer I — Mastercard

### Our purpose

Mastercard powers economies and supports people across more than 200 countries and territories. It
provides digital-payment products and services intended to make transactions secure, simple, smart,
and accessible for people, businesses, and governments.

### Role overview

The Software Development Engineer is an early-career engineer specializing in Java development and
microservices for Mastercard's high-throughput, low-latency transaction-processing platforms. The
role contributes to the development, testing, deployment, and support of business-critical
applications while learning modern software-engineering practices from experienced engineers.

### What you'll do

- Translate product requirements into technical implementations with guidance from senior engineers.
- Contribute to software-design discussions and propose scalable, maintainable solutions.
- Write modular, readable, and performant code following engineering best practices.
- Develop and maintain unit tests and automated test coverage.
- Participate in functional and integration testing across applications and services.
- Follow secure-coding standards throughout the software-development lifecycle.
- Participate in peer code reviews and incorporate feedback.
- Assist with prototypes and proof-of-concept work.
- Support cloud-ready microservices and distributed applications.
- Troubleshoot software defects and production issues.
- Build applications with maintainability, reliability, and operational readiness in mind.
- Collaborate with cross-functional teams using Agile Scrum practices.

### Qualifications

- Good understanding of Java, J2EE, Spring, Spring Boot, Kafka, RESTful web services, and JPA.
- Foundational understanding of software design and architecture.
- Familiarity with unit, functional, and integration testing.
- Understanding of secure-coding principles.
- Strong problem-solving and analytical skills.
- Strong understanding of data structures and their effect on application performance.
- Exposure to microservices and cloud-native application development.
- Exposure to CI/CD practices and Test-Driven Development.
- Strong communication skills and willingness to learn from experienced engineers.
- Knowledge or experience with AI-assisted applications, AI agents, or agentic workflows is a plus.

### Corporate security responsibility

Employees must follow Mastercard's security policies, protect the confidentiality and integrity of
the information they access, report suspected security violations, and complete required security
training.
