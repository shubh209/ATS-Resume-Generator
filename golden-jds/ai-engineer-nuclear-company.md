## AI Engineer 1 — Platform Integration & AI/Data (The Nuclear Company)

### About the role

The Nuclear Company builds NOS, the software platform behind one of the largest nuclear buildouts in
the US. This role helps build and run the backend, data, and integration layers NOS depends on,
reporting to the Director of Platform Integrations inside the Platform Integration & AI/Data squad.
Hands-on and entry-level: work alongside the Platform Engineer and senior engineers on CI/CD, backend
services, and data/application integrations, taking well-scoped features end to end under senior code
review. Ramp on Palantir Foundry and the team's AI and data tooling, write production code, open pull
requests, and grow into a specialization over time.

### Responsibilities (first 90 days)

- Help build and maintain application and data integrations connecting NOS to internal systems,
  partner APIs, and external data sources, from well-scoped tickets under senior review.
- Take ownership of scoped CI/CD and release tasks that keep NOS builds repeatable, tested, and traceable.
- Basic backend and DevOps work: build and fix backend services, write tests, handle routine platform
  monitoring and maintenance.
- Ramp on Palantir Foundry, the data ontology, and the MCP interfaces that let AI agents work against
  NOS data, and start contributing to them.
- Partner with the Platform Engineer, data scientists, AI/ML engineers, and product engineers, growing
  from paired work toward independent delivery.

### Required experience

- CS degree or equivalent, 0-2 years professional experience (internships, co-ops, project work count).
- Strong fundamentals in at least one backend language (Python and/or TypeScript preferred; Go or Java welcome).
- Some hands-on exposure to basic DevOps and backend work: CI/CD, version control, REST APIs, or wiring
  systems together, from an internship, job, or personal project.
- Has built something with AI beyond using a chat assistant: multi-step prompts, custom tools, AI in
  the codebase, or a small agentic project.
- Good written and verbal communication, willingness to learn the nuclear and regulated-industry context.

### Preferred experience

- Exposure to a major cloud (AWS preferred), including coursework or personal projects.
- Coursework or project work in CI/CD, infrastructure as code, or configuration management.
- Coursework or project work in LLMs, agentic systems, or data modeling.
- Familiarity with Palantir Foundry, Databricks, or Snowflake.
- Internship or project work in a regulated or mega-project industry (nuclear, aerospace, defense,
  energy, medical).

### Candidate-fit notes (for regression testing, not part of the JD)

- Strongest matches: Hearloop (async data pipeline with Node.js/BullMQ/Redis, AWS Bedrock
  classification, Docker + GitHub Actions CI/CD, REST APIs on AWS) covers the "built something with AI
  beyond a chat assistant" bar plus CI/CD and integration wiring; eInfochips (REST APIs, AWS, GitHub
  Actions pipeline, RBAC) covers backend + DevOps fundamentals; SEO Audit Engine / ClusterOps add
  backend services, queues, and Go/data ingestion.
- Entry-level fit is strong: 0-2 years with project work counting matches an MS CS new grad profile.
  Tailoring should NOT inflate to independent senior ownership; the role is paired/under-review.
- Real gaps to handle honestly (do not invent): Palantir Foundry, Databricks, Snowflake, and MCP
  interfaces are named but not in the candidate's master facts. AWS Bedrock is the closest real LLM
  tooling anchor; agentic/MCP work should be framed as adjacent and a ramp target, not shipped.
- Nuclear/regulated-industry context is a willingness-to-learn item, not a hard requirement.
